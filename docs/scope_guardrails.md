# Scope Guardrails

Status: Foundation placeholder for Slice 0.3 compatibility.

## In Scope

- Deterministic market analysis
- Replayable core pipeline
- Evidence-backed events
- Persian-first reporting outputs
- English code and contracts

## Out of Scope

- Order execution
- Broker or exchange automation
- Wallet signing
- Portfolio management
- Position sizing
- Leverage logic
- Live trading decisions
- ML or AI as source of deterministic truth

## Explicitly Excluded Responsibilities

- trade execution
- broker side effects
- portfolio management
- ML-driven truth generation
- canonical serialization
