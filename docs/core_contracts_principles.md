# Core Contracts Principles

Status: Foundation placeholder for Slice 0.3 compatibility.

## Principles

Core contracts must be:

- immutable
- typed
- explicit
- deterministic
- replayable
- serializable through a canonical policy
- independent from hidden wall-clock time
- independent from runtime randomness
- explainable with evidence and reason codes

## Rule

No Python contract implementation is frozen by this document. Contract shape belongs to a later slice.
