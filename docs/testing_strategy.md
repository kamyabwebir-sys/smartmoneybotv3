# Testing Strategy

Status: Foundation placeholder for Slice 0.3 compatibility.

## Foundation Tests

Foundation tests verify project layout, required governance files, and semantic documentation presence.

## Domain Tests

Future domain tests must verify deterministic behavior using fixed inputs and expected outputs.

## Replay Tests

Replay tests must prove that the same canonical input sequence and frozen rules produce the same outputs.

## Golden Tests

Golden snapshots may be added only after canonical serialization is frozen.
